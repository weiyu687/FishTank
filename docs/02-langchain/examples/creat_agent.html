  1. 初始化工具列表

工具重要参数：

  • name
  • description
  • args_schema

@tool作用：

  1. 生成tool description

将函数的文档字符串""" """变为工具描述。数据类型是string。

  1. 生成tool args_schema

读取函数的type hint,生成符合OpenAI function calling的参数结构。

  1. 将普通函数变为Base Tool对象

包装后函数拥有.name、.description、.args_schema属性，传给bind_tools或者create_agent。

  1. 适配LangGraph的ToolNode

LangGraph中的ToolNode会自动识别@tool装饰的工具， 自动执行、把结果包装成ToolMessage, 不需要处理消息转换

from langchain_core.tools import tool
from langchain_core.messages import HumanMessage

@tool
def get_weather(city: str) -> str:
    """返回该城市的天气情况
    
    Args:
        city: 城市名

    Returns:
        str: 该城市的天气情况，例如"晴天"
    """
    return f"{city}当前天气：晴天"

chat_model_with_tools = chat_model.bind_tools([get_weather])

res = chat_model_with_tools.invoke([HumanMessage(content="贵阳天气怎么样？")])

print("res.tool_calls:", res.tool_calls)
res.tool_calls: [{'name': 'get_weather', 'args': {'city': '贵阳'}, 'id': 'call_00_a29QQS5WGWYb2oCUi2HJ9437', 'type': 'tool_call'}]

chat_model通过 bind_tools绑定tool list后，当识别到存在工具调用的需求，会返回tool_calls表示需要调用工具，chat_model没有工具调用的能力，因为其只是LLM，不是Agent

  1. 初始化智能体

不同于 chat_model, agent拥有了工具调用的能力,遵守ReAct模式, 即reasoning->action->observation的不断循环， 具体可查阅论文ReAct: Synergizing Reasoning and Acting in Language Models

from langchain.agents import create_agent
from langchain_core.messages import HumanMessage

agent = create_agent(
    model=chat_model,
    tools=[get_weather],
    system_prompt="You are a helpful assistant"
)
# 5. 测试智能体

res = agent.invoke(
    {
        "messages":[
            HumanMessage(content="贵阳天气怎么样？")
        ]
    }
)

print(res["messages"][-1].content_blocks)
