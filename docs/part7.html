PART VII · FLOW MATCHING

Flow Matching：直接学习“样本应该往哪里流”

Diffusion 把生成写成很多个去噪步骤。Flow Matching 把时间变成连续变量，并把生成问题写成一个更直接的问题：在每个时间 t、空间位置 x，样本应该以怎样的速度移动，才能把简单分布运输成数据分布？

这一 Part 的最终目标

理解并能够自己解释：

\[ \frac{dx_t}{dt}=v_\theta(x_t,t) \]

以及训练目标：

\[ \mathcal L_{CFM} = \mathbb E \left[ \|v_\theta(x_t,t)-u_t(x_t|z)\|^2 \right] \]

这里的每个符号都会从 ODE、向量场和概率路径自然产生，而不是突然出现。

先把 Flow Matching 与 Diffusion 的问题语言区分开

Diffusion 常见语言

给数据加噪，学习反向去噪或 score。

Flow Matching 语言

指定一条概率路径，直接学习产生这条路径的速度场。

共同目标

把简单基础分布运输到复杂数据分布。

Flow Matching 最初是作为训练 Continuous Normalizing Flows 的 simulation-free 方法提出的；它可以使用扩散式概率路径，也可以使用其他路径，例如 Optimal Transport 风格的路径。

43 · 从离散步骤到连续时间

43.1 Diffusion 的离散时间

上一 Part 中时间是：

\[ t=0,1,2,\ldots,T \]

状态按照：

\[ x_T\to x_{T-1}\to\cdots\to x_0 \]

一步步变化。

43.2 如果时间步越来越小

把总时间缩放到区间：

\[ t\in[0,1] \]

并让每一步间隔：

\[ \Delta t \]

越来越小。

离散更新：

\[ x_{t+\Delta t} = x_t + v_t(x_t)\Delta t \]

两边减去 \(x_t\)，再除以 \(\Delta t\)：

\[ \frac{x_{t+\Delta t}-x_t}{\Delta t} = v_t(x_t) \]

让 \(\Delta t\to0\)，左边就是导数：

\[ \boxed{ \frac{dx_t}{dt} = v_t(x_t) } \]

43.3 这条式子的直觉

它说的只是：

当前位置 x + 当前速度 v × 极短时间 dt → 下一瞬间的位置

Flow Matching 的主要对象，就是这个随时间变化的速度函数 \(v_t(x)\)。

44 · ODE：已知速度规则，怎样得到完整轨迹？

44.1 ODE 是什么？

ODE 是 Ordinary Differential Equation，常微分方程。

最简单形式：

\[ \frac{dx}{dt}=v(x,t) \]

它没有直接告诉我们 x 在每个时刻是多少，而是告诉我们“每一时刻应该怎样变化”。

44.2 最简单例子

如果：

\[ \frac{dx}{dt}=2 \]

表示速度恒定为 2。若：

\[ x(0)=3 \]

那么：

\[ x(t)=3+2t \]

44.3 速度依赖当前位置

如果：

\[ \frac{dx}{dt}=-x \]

当前位置为正时速度向左，当前位置越远速度越大。它的解是：

\[ x(t)=x(0)e^{-t} \]

所以所有点都会逐渐靠近 0。

44.4 生成模型需要多维 ODE

图像或潜变量是向量：

\[ x(t)\in\mathbb R^d \]

因此速度也是向量：

\[ v_t(x)\in\mathbb R^d \]

ODE：

\[ \frac{dx_t}{dt}=v_t(x_t) \]

表示 d 个坐标同时按速度场变化。

44.5 没有解析解怎么办？

神经网络定义的 \(v_\theta(x,t)\) 通常没有像 \(3+2t\) 那样简单的闭式解，所以采样时使用数值 ODE solver。

最简单的 Euler 方法：

\[ x_{t+\Delta t} \approx x_t+ v_\theta(x_t,t)\Delta t \]

更高阶方法会更精确，但主线思想不变。

45 · 向量场：空间中的每个位置都有一个箭头

45.1 从单个速度到整张“速度地图”

函数：

\[ v_t:\mathbb R^d\to\mathbb R^d \]

对每个位置 x 都给出一个速度向量。

在二维空间中，可以想象平面上的每一个点都放着一支箭头：

箭头方向 = 应该往哪里移动　　箭头长度 = 移动速度有多大

整套箭头就叫向量场（vector field）。

45.2 时间相关向量场

Flow Matching 使用：

\[ v_t(x) \]

因此同一个空间位置 x，在不同时间 t 可以有不同箭头。

45.3 一个样本的轨迹

从初始点：

\[ x_0 \]

出发，遵循 ODE：

\[ \frac{dx_t}{dt}=v_t(x_t) \]

会得到一条连续轨迹：

\[ x_0\to x_{0.1}\to x_{0.2}\to\cdots\to x_1 \]

45.4 Flow 是什么？

如果对每一个初始点都运行这个 ODE，就得到一个随时间变化的映射：

\[ \phi_t(x_0)=x_t \]

它把初始空间中的点整体搬运到 t 时刻的位置，这个映射族常称为 flow。

46 · 不只是点在移动：整个概率分布也在移动

46.1 从一堆粒子理解分布

假设初始时刻采样很多点：

\[ x_0^{(1)},x_0^{(2)},\ldots \sim p_0 \]

每一个点都遵循同一个 ODE。

在 t 时刻，这些点形成新的分布：

\[ p_t(x) \]

46.2 生成模型希望什么？

通常选择简单基础分布：

\[ p_0=p_{base} \]

例如：

\[ p_0=\mathcal N(0,I) \]

希望经过流之后：

\[ p_1=p_{data} \]

因此：

简单噪声分布 \(p_0\) → 连续向量场运输 → 数据分布 \(p_1\)

46.3 “概率路径”是什么？

从 \(p_0\) 到 \(p_1\) 的整个中间分布族：

\[ p_t,\qquad t\in[0,1] \]

叫概率路径（probability path）。

注意：

概率路径不是单个样本的轨迹

\(x_t\) 描述一个粒子怎样移动；\(p_t\) 描述无数粒子在时刻 t 的整体分布。

47 · 连续性方程：概率质量不能凭空消失

47.1 从水流直觉开始

想象一个装满水的管道。某个小区域里的水量减少，只可能因为流出去的水比流进来的多；如果没有水源或排水口，水不能凭空消失。

概率密度在向量场中运动也是同样道理。

47.2 散度 divergence

对向量场：

\[ v(x) = (v_1(x),\ldots,v_d(x)) \]

定义散度：

\[ \nabla\cdot v = \sum_{i=1}^{d} \frac{\partial v_i}{\partial x_i} \]

直觉上，它描述一个极小区域附近“总体往外流”的程度。

47.3 连续性方程

概率密度 \(p_t(x)\) 在速度场 \(v_t(x)\) 下演化必须满足：

\[ \boxed{ \frac{\partial p_t(x)}{\partial t} + \nabla\cdot \left( p_t(x)v_t(x) \right) = 0 } \]

第一项表示某位置概率密度随时间的变化。

第二项表示概率流 \(p_tv_t\) 从该区域净流出的程度。

47.4 为什么这个方程重要？

ODE：

\[ \dot x_t=v_t(x_t) \]

描述单个粒子怎么走；连续性方程：

\[ \partial_t p_t+\nabla\cdot(p_tv_t)=0 \]

描述一整群粒子的概率分布怎么变。

Flow Matching 的核心任务

给定想要的概率路径 \(p_t\)，找到或学习一个速度场 \(v_t\)，使它通过连续性方程真正生成这条概率路径。

48 · Continuous Normalizing Flow：用 ODE 运输概率分布

48.1 Normalizing Flow 的目标

Normalizing Flow 希望建立简单分布与复杂数据分布之间的可逆变换。

Continuous Normalizing Flow（CNF）把变换写成连续 ODE：

\[ \frac{dx_t}{dt}=v_\theta(x_t,t) \]

48.2 从基础分布采样

\[ x_0\sim p_0 \]

运行 ODE 到 t=1：

\[ x_1=\phi_1(x_0) \]

如果学习正确，最终：

\[ x_1\sim p_{data} \]

48.3 密度本身怎样沿 ODE 改变？

沿着轨迹，可以得到瞬时 change-of-variables 关系：

\[ \frac{d}{dt}\log p_t(x_t) = - \nabla\cdot v_t(x_t) \]

这可以从连续性方程推导得到。它允许 CNF 计算 likelihood，但传统 maximum-likelihood 训练往往需要同时求解 ODE，并计算 divergence，成本较高。

48.4 Flow Matching 改变训练方式

Flow Matching 的关键贡献之一，就是：

不在训练过程中模拟模型 ODE → 直接把速度场学习变成监督回归

这就是“simulation-free training”的含义。生成时仍需要积分 ODE，但训练目标本身不需要先运行当前模型的完整 flow。

49 · Flow Matching：如果知道正确速度场，直接回归它

49.1 假设我们已经选好概率路径

设：

\[ p_t(x),\qquad t\in[0,1] \]

满足：

\[ p_0=p_{base},\qquad p_1=p_{data} \]

假设还存在一个真实速度场：

\[ u_t(x) \]

它通过连续性方程生成这条路径。

49.2 最自然的监督学习目标

用神经网络：

\[ v_\theta(x,t) \]

去拟合真实速度：

\[ \boxed{ \mathcal L_{FM}(\theta) = \mathbb E_{ t\sim U[0,1], x\sim p_t } \left[ \| v_\theta(x,t)-u_t(x) \|^2 \right] } \]

49.3 为什么这么简单？

如果对所有 t 和 x 都有：

\[ v_\theta(x,t)=u_t(x) \]

那么神经 ODE 就拥有生成 \(p_t\) 的正确速度场，因此从 \(p_0\) 积分到 t=1 就能得到 \(p_1\)。

49.4 这里与 Diffusion 噪声 MSE 的相似性

Diffusion

回归噪声 / score。

Flow Matching

回归速度向量。

共同结构

把生成问题转化成在随机时间和随机位置上的监督回归。

49.5 真正困难在哪里？

这个目标虽然漂亮，但里面需要：

\[ u_t(x) \]

即边缘概率路径 \(p_t\) 的真实速度场。对于复杂数据分布，我们通常并不知道它。

所以直接 Flow Matching 目标看起来又陷入了一个类似 VAE 的问题：理论目标很好，但监督信号本身难算。

50 · 为什么直接 FM 难训练？“边缘速度场”从哪里来？

50.1 我们拥有的是样本，不是完整数据密度

现实里我们有数据集：

\[ x_1\sim p_{data} \]

但一般不知道 \(p_{data}(x)\) 的解析表达式，更不知道中间的：

\[ p_t(x) \]

以及它的速度场：

\[ u_t(x) \]

50.2 想法：把复杂边缘路径拆成简单条件路径

与 VAE 的思路有一点相似：困难对象不直接算，而是引入条件结构。

我们先选一个条件变量 z，并为每个 z 定义容易处理的条件概率路径：

\[ p_t(x|z) \]

以及对应的条件速度场：

\[ u_t(x|z) \]

如果这些条件对象容易采样、速度也能解析计算，那么就有了监督信号。

50.3 边缘路径由条件路径混合得到

设 z 服从某个分布 q(z)：

\[ p_t(x) = \int p_t(x|z)q(z)dz \]

大量简单条件路径混合起来，就形成真正想要的边缘概率路径。

51 · Conditional Flow Matching：为什么条件速度可以训练边缘速度？

51.1 条件训练目标

Conditional Flow Matching（CFM）使用：

\[ \boxed{ \mathcal L_{CFM} = \mathbb E_{ t,z,x\sim p_t(x|z) } \left[ \| v_\theta(x,t) - u_t(x|z) \|^2 \right] } \]

现在 target：

\[ u_t(x|z) \]

是我们人为选择的简单条件路径所对应的速度，因此可以计算。

51.2 但网络没有看到 z，怎么可能同时匹配不同条件速度？

这是 CFM 最关键的一点。

固定某个 \((x,t)\)。不同条件 z 可能产生同一个位置 x，但给出不同条件速度：

\[ u_t(x|z) \]

网络只输入 x,t，因此无法分别记住每个 z。平方误差的最优预测会取条件平均：

\[ v^*(x,t) = \mathbb E[ u_t(x|z) \mid x_t=x ] \]

51.3 为什么平方误差的最优解是条件期望？

对固定 x，把随机 target 记作 U，预测一个向量 a。考虑：

\[ \mathbb E[\|a-U\|^2|x] \]

令：

\[ m=\mathbb E[U|x] \]

加入并减去 m：

\[ a-U=(a-m)+(m-U) \]

平方并取期望，交叉项为 0，因为：

\[ \mathbb E[m-U|x]=0 \]

所以：

\[ \mathbb E[\|a-U\|^2|x] = \|a-m\|^2 + \mathbb E[\|m-U\|^2|x] \]

第二项与 a 无关，因此最小时：

\[ a=m \]

也就是条件期望。

51.4 这个条件平均恰好是什么？

在适当正则条件下：

\[ \boxed{ u_t(x) = \mathbb E[ u_t(x|z) \mid x_t=x ] } \]

正是生成边缘路径 \(p_t(x)\) 的边缘速度场。

CFM 的核心魔法并不是魔法

我们用容易计算的“条件速度”作为随机监督标签；神经网络在平方误差下学到它们对给定 x,t 的条件平均，而这个平均恰好是我们真正想要、却难以直接计算的边缘速度场。

51.5 FM 与 CFM 的目标关系

在常见条件下，CFM 与边缘 FM 对参数 \(\theta\) 具有相同的梯度；两者只相差与模型参数无关的项。因此优化 CFM 可以训练出同一个目标边缘场，而不必显式知道边缘速度。

52 · 最直观的条件路径：在噪声与数据之间画直线

52.1 取两个端点

从基础分布采样：

\[ x_0\sim p_0 \]

从数据分布采样：

\[ x_1\sim p_1=p_{data} \]

52.2 定义线性插值

\[ \boxed{ x_t=(1-t)x_0+t x_1 } \]

检查端点：

\[ x_{t=0}=x_0 \] \[ x_{t=1}=x_1 \]

52.3 对时间求导

\[ \frac{dx_t}{dt} = -x_0+x_1 \]

所以这条单个条件轨迹的速度为：

\[ \boxed{ u_t=x_1-x_0 } \]

它甚至不依赖 t：每个样本沿直线以恒定速度从 x0 走到 x1。

52.4 于是训练变得异常直接

采样：

\[ t\sim U[0,1] \] \[ x_0\sim p_0,\qquad x_1\sim p_{data} \]

构造：

\[ x_t=(1-t)x_0+t x_1 \]

target：

\[ u=x_1-x_0 \]

Loss：

\[ \boxed{ \mathcal L = \mathbb E [ \| v_\theta(x_t,t)-(x_1-x_0) \|^2 ] } \]

52.5 这就是所有 Flow Matching 吗？

不是。这是非常重要、直观的一类路径，但 Flow Matching 的框架允许更一般的概率路径，包括 Gaussian / diffusion-style paths。

原始 Flow Matching 工作的重要观点之一正是：训练方法与具体路径设计可以分离。

52.6 source-target 配对很重要

如果 x0 与 x1 完全独立随机配对，很多直线路径可能相互穿越，边缘速度场需要对冲这些不同方向。

这不会让 CFM 理论失效，但可能让学到的流更弯、更复杂，数值积分需要更多工作。

53 · Optimal Transport：为什么“更聪明地配对”能得到更直的流？

53.1 配对就是 coupling

我们不一定要独立采样 x0 和 x1。可以定义一个联合分布：

\[ \pi(x_0,x_1) \]

要求它的两个边缘分别仍是：

\[ p_0(x_0),\qquad p_1(x_1) \]

这样的联合分布叫 coupling。

53.2 不同 coupling 会产生不同运输路径

例如二维空间中，噪声点在左边、数据点在右边。若随意配对，直线可能大量交叉。

如果配对尽可能让相近、合理的端点对应，整体运输可能更简单。

53.3 Optimal Transport 的基本目标

经典平方欧氏成本下，可以寻找：

\[ \min_{\pi} \mathbb E_{(x_0,x_1)\sim\pi} [ \|x_1-x_0\|^2 ] \]

同时保持正确的 source / target 边缘分布。

53.4 OT-CFM 的直觉

如果用更接近 Optimal Transport 的 coupling，再沿端点做条件插值，通常会得到：

更短、更一致的运输方向 → 更简单的向量场 → ODE 数值积分更容易

后续 Conditional Flow Matching 工作提出了 OT-CFM 等变体，以更好的 coupling 构造更简单的流。

53.5 “直线条件路径”不等于“边缘轨迹一定全部是直线”

这是一个重要区分。

训练标签来自每对 \((x_0,x_1)\) 的直线条件速度，但网络最终学的是这些条件速度在同一 \((x,t)\) 位置下的平均边缘场。

因此神经 ODE 真正生成时的轨迹由边缘场决定，未必与训练中任何一条具体条件直线完全相同。

54 · Flow Matching 与 Diffusion / Score 到底是什么关系？

54.1 它们都在构造中间概率路径

Diffusion 有：

\[ p_t \]

从数据逐渐走向噪声；生成时反过来。

Flow Matching 同样关心：

\[ p_t \]

但直接学习产生概率路径的确定性速度场。

54.2 Diffusion 常学习 score

\[ s_t(x) = \nabla_x\log p_t(x) \]

它告诉我们当前密度“往高概率区域增长最快的方向”。

54.3 Flow Matching 学 velocity

\[ v_t(x) \]

它告诉我们粒子在此时此地“实际应该以什么速度移动”。

score 与 velocity 不是同一个对象

score 是一个概率密度的空间梯度；velocity 是概率质量运输的动力学速度。在特定 diffusion/SDE 路径下，二者可以通过已知漂移、扩散系数建立关系，但不能直接把两个符号画等号。

54.4 Probability Flow ODE 提供桥梁

连续时间 diffusion 可以写成 SDE，例如抽象形式：

\[ dx=f(x,t)dt+g(t)dW_t \]

存在一个确定性的 probability flow ODE，其速度场包含 score 项，形式为：

\[ \frac{dx}{dt} = f(x,t) - \frac12g(t)^2 \nabla_x\log p_t(x) \]

这个 ODE 与相应 SDE 可以共享相同的时刻边缘分布。

因此：

Score-based Diffusion ← 概率路径 → Probability Flow ODE → Flow / Vector-field 视角

54.5 Flow Matching 可以使用 diffusion path

Flow Matching 并不要求概率路径必须是直线。原始 FM 框架明确允许 Gaussian probability paths，并包含 diffusion paths 作为重要特例。

所以“Diffusion 和 Flow Matching”不是两个完全没有交集的世界，更准确地说，它们是对连续生成动力学的不同参数化与训练方式。

55 · 一个完整 Flow Matching 模型怎样训练和生成？

55.1 训练：最简单线性 CFM 版本

步骤 1：采基础样本

\[ x_0\sim p_0 \]

例如标准高斯。

步骤 2：采数据

\[ x_1\sim p_{data} \]

步骤 3：采时间

\[ t\sim U[0,1] \]

步骤 4：构造中间点

\[ x_t=(1-t)x_0+t x_1 \]

步骤 5：计算条件速度 target

\[ u=x_1-x_0 \]

步骤 6：网络回归速度

\[ \mathcal L = \| v_\theta(x_t,t)-u \|^2 \]

55.2 与 Diffusion 训练流程对比

Diffusion

采 \(x_0,t,\epsilon\) → 构造带噪 \(x_t\) → 预测 \(\epsilon\) 或 score。

Flow Matching

采 source、target、t → 构造路径中间点 → 预测 velocity。

相同风格

都无需在每个 SGD step 中先完整运行生成轨迹，再获得训练标签。

55.3 生成

训练结束后：

\[ x(0)\sim p_0 \]

求解：

\[ \frac{dx(t)}{dt} = v_\theta(x(t),t) \]

从 t=0 积分到 t=1：

\[ x(1)\approx p_{data} \]

55.4 生成时为什么不再需要 x1？

训练时 x1 只用于构造条件路径和速度监督。

神经网络学到的是边缘速度函数：

\[ v_\theta(x,t) \]

推理时给它当前 x 和 t 就可以决定下一步移动方向，不需要提前知道最终真实样本。

55.5 条件生成怎么办？

如果希望按文字、类别、图像条件 c 生成，可以把条件一起送入速度网络：

\[ v_\theta(x,t,c) \]

这里 c 是“生成条件”，与 CFM 中用来构造条件概率路径的数学 conditioning variable 不应机械混为一个概念。二者可以同时存在。

Part VII · Flow Matching 知识闭环

1. 样本按照 ODE 移动

\[ \boxed{ \frac{dx_t}{dt} = v_t(x_t) } \]

2. 向量场推动整个概率分布

\[ p_0 \xrightarrow{v_t} p_t \xrightarrow{v_t} p_1 \]

3. 概率守恒由连续性方程描述

\[ \boxed{ \partial_t p_t + \nabla\cdot(p_tv_t) = 0 } \]

4. 理想 Flow Matching

\[ \mathcal L_{FM} = \mathbb E_{t,x\sim p_t} [ \|v_\theta(x,t)-u_t(x)\|^2 ] \]

5. 边缘速度难算，于是构造条件路径

\[ p_t(x) = \int p_t(x|z)q(z)dz \]

6. Conditional Flow Matching

\[ \boxed{ \mathcal L_{CFM} = \mathbb E [ \|v_\theta(x_t,t)-u_t(x_t|z)\|^2 ] } \]

7. CFM 为什么有效

\[ \boxed{ u_t(x) = \mathbb E[ u_t(x|z) \mid x_t=x ] } \]

平方回归会自动学到这个条件平均，因此恢复真正需要的边缘速度场。

8. 最简单线性路径

\[ x_t=(1-t)x_0+t x_1 \] \[ \boxed{ u_t=x_1-x_0 } \]

9. 生成只需解 ODE

\[ x_0\sim p_{base} \] \[ \dot x_t=v_\theta(x_t,t) \] \[ x_1\sim p_{data} \]
到这里可以用一句话区分三个模型

VAE：学习潜变量概率模型并优化 ELBO。
Diffusion：学习如何逆转逐步噪声过程，常参数化噪声或 score。
Flow Matching：选定概率路径，直接监督学习推动该路径的速度场。
