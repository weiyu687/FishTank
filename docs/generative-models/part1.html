FROM FIRST PRINCIPLES

从零开始理解生成模型的数学

这不是一份“记住 VAE 公式”的笔记。目标是从最基本的数学语言出发，让每一个后来出现的符号都有来处，最终自然走到 VAE、扩散模型与 Flow Matching。

阅读原则

每引入一个新概念，我们回答三件事：它直觉上是什么？数学上为什么这样写？未来在生成模型的哪里出现？如果一个结论暂时作为定理使用，会明确标注，而不会把未知步骤藏在“显然”二字里。

我们最终要看懂什么？

以 VAE 为第一个里程碑。最终你会独立理解：

\[\mathcal L_{VAE}=-\mathbb E_{q_\phi(z|x)}[\log p_\theta(x|z)]+D_{KL}(q_\phi(z|x)\|p(z))\]

现在不需要理解它。Part I 的任务，是建立足够精确的数学语言，使后面的概率模型不再像突然出现的魔法。

PART I

数学语言：先学会准确地说话

概率论最容易造成的错觉是“公式看懂了”。真正困难的是：每个符号究竟指对象、函数、数值，还是一个分布？这一 Part 专门消除这种歧义。

01 · 函数、变量与符号

1.1 变量不是神秘的字母

写 \(x=3\) 时，x 只是一个名字，它当前代表数字 3。机器学习里，x 常被约定为数据。例如一张 28×28 灰度图可以展开成 784 个数，因此这里的 x 不一定是一个标量，而可以是向量。

例子

若一张极小的 2×2 灰度图为 \(\begin{bmatrix}0&1\\0.5&0.2\end{bmatrix}\)，可以把它表示成 \(x=(0,1,0.5,0.2)\)。所以“输入 x”可以是一整个对象。

1.2 函数是输入到输出的规则

函数写作 \(y=f(x)\)。它表达：给定 x，按照规则 f 得到 y。神经网络本质上也是参数化函数：

\[y=f_\theta(x)\]

下标 \(\theta\) 表示函数的行为由一组参数控制。训练神经网络，本质上是在寻找合适的 \(\theta\)。

1.3 映射与“维度”

如果输入是 784 个数、输出是 2 个数，可写作 \(f:\mathbb R^{784}\to\mathbb R^2\)。这正是普通 AutoEncoder 的 Encoder 可以做的事情。后面 VAE 会把“输出一个点”改成“输出一个分布的参数”。

1.4 先分清确定性与随机性

普通函数中，同一个 x 输入同一个确定函数，会得到同一个结果。概率模型则允许结果带有不确定性。为了准确描述这种不确定性，我们才需要概率。

02 · 概率是什么？

2.1 从事件开始

概率用一个 0 到 1 的数描述事件发生的可能性。记事件为 A，则 \(P(A)\in[0,1]\)。0 表示不可能，1 表示必然。

对于均匀六面骰子，事件 A=“掷出偶数”，有三个有利结果 {2,4,6}，因此 \(P(A)=3/6=1/2\)。

2.2 为什么机器学习需要概率？

真实数据往往不能由一个简单确定规则完整描述。同一类别的手写数字 3 可以有无数种写法。生成模型不是只想记住一张固定图片，而是要描述“什么样的 x 是合理的、各自有多可能”。于是我们希望学习一个分布 \(p(x)\)。

连接到生成模型

如果模型真正学到了数据分布 \(p_{data}(x)\)，理论上就能从这个分布采样，产生新的合理数据。生成建模的核心问题由此出现：如何表示、学习并从复杂的高维分布中采样？

2.3 联合概率

若同时关心两个对象 x 与 z，\(p(x,z)\) 描述它们共同出现的概率规律。这个记号以后极其重要，因为潜变量模型会把“可观察的 x”和“看不见的 z”放在同一个联合分布中。

03 · 条件概率：知道信息之后，概率如何改变？

3.1 为什么需要条件

“一个人下雨天带伞的概率”和“不知道天气时带伞的概率”显然不同。符号 \(P(A|B)\) 表示：已经知道 B 发生的条件下，A 发生的概率。

\[P(A|B)=\frac{P(A\cap B)}{P(B)},\qquad P(B)>0\]

分子只保留 A 与 B 同时发生的部分；分母把我们新的观察范围限制在 B 内。因此条件概率不是凭空增加一个竖线，而是在已知信息后重新缩小样本空间。

3.2 乘法法则从哪里来

把定义两边乘以 \(P(B)\)：

\[P(A\cap B)=P(A|B)P(B)\]

连续变量以后写成：

\[p(x,z)=p(x|z)p(z)\]

这条公式就是生成模型的一个基本故事：先按 \(p(z)\) 得到 z，再按 \(p(x|z)\) 产生 x。

3.3 贝叶斯公式其实只是同一个联合概率写两次

\[p(x,z)=p(x|z)p(z)=p(z|x)p(x)\]

因此：

\[p(z|x)=\frac{p(x|z)p(z)}{p(x)}\]

我们现在只建立来源，不急着讨论“先验/后验”。等到潜变量模型时，这些名字会有明确对象，而不是术语堆砌。

04 · 随机变量：把随机结果变成可计算的数

随机变量不是“自己随机变化的变量”。更准确地说，它是一个函数：把随机实验的结果映射成数字。掷两枚硬币时，样本结果可以是 HH、HT、TH、TT。定义 X=“正面个数”，则 X 分别取 2、1、1、0。

这样做的价值是：原本各种形式的随机结果被转化为数字，于是我们可以计算平均值、方差，并用函数描述它们的分布。

4.1 离散与连续

骰子点数只有有限个分离取值，是离散随机变量；身高、温度以及许多模型中的潜变量通常用连续随机变量建模。两者最大的技术差别之一，是连续情形需要“概率密度”。

常见误解

大写 \(X\) 常表示随机变量，小写 \(x\) 常表示它的一次具体取值。这只是常见约定，不是数学定律，但读论文时非常有用。

05 · 概率分布与概率密度

5.1 离散变量：直接给每个值概率

公平骰子的 \(P(X=k)=1/6\)。把所有可能取值的概率加起来必须为 1。

\[\sum_x p(x)=1\]

5.2 连续变量为什么不能照搬？

假设 X 可以在实数轴连续取值。单个点没有宽度，因此对通常的连续分布，\(P(X=x)=0\)。这并不意味着 x 附近不可能出现。我们真正计算的是一个区间的概率。

\[P(a\le X\le b)=\int_a^b p(x)\,dx\]

这里 \(p(x)\) 是概率密度，曲线在区间下的面积才是概率。因此“密度值”和“概率”不能混为一谈。

5.3 密度必须归一化

\[\int_{-\infty}^{\infty}p(x)\,dx=1\]

后面出现的高斯分布、\(q(z|x)\)、\(p(z)\) 都遵守同一个规则。到那时积分符号不会再是突然出现的新东西。

06 · 期望与方差：一个分布的中心与波动

6.1 期望不是“最可能的值”

期望描述大量重复实验后的加权平均。离散情况下：

\[\mathbb E[X]=\sum_x x\,p(x)\]

连续情况下把求和自然替换为积分：

\[\mathbb E[X]=\int x\,p(x)\,dx\]

更一般地，对 X 的函数 g(X)：

\[\mathbb E[g(X)]=\int g(x)p(x)\,dx\]
这条式子以后会直接回来

VAE 中 \(\mathbb E_{q(z|x)}[\log p(x|z)]\) 的意思并不神秘：让 z 按 \(q(z|x)\) 分布时，对 \(\log p(x|z)\) 做加权平均。

6.2 方差为什么需要平方

只计算 \(X-\mathbb E[X]\) 的平均会正负抵消，因此用平方衡量偏离中心的程度：

\[\mathrm{Var}(X)=\mathbb E[(X-\mu)^2],\qquad \mu=\mathbb E[X]\]

标准差定义为 \(\sigma=\sqrt{\mathrm{Var}(X)}\)，因此方差是 \(\sigma^2\)。下一 Part 学高斯分布 \(\mathcal N(\mu,\sigma^2)\) 时，这两个参数已经不再陌生。

6.3 Part I 的知识闭环

现在我们已经拥有一条完整语言链：

随机现象 → 随机变量 X → 分布 p(x) → 条件分布 p(x|z) → 期望 E[X] → 方差 Var(X)
