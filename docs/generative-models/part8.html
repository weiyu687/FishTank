PART VIII · A UNIFIED VIEW

统一视角：VAE、Diffusion、Score 与 Flow Matching 到底在做同一件什么事？

前面七个 Part 分别建立了概率、变分推断、VAE、Diffusion 与 Flow Matching。最后这一 Part 不再追求“更多公式”，而是回答一个更重要的问题：这些模型为什么看起来完全不同，却又不断出现高斯、KL、噪声、score、velocity 和 ODE？

统一，但不混淆

这些模型都试图学习复杂数据分布，但它们选择的隐藏变量、训练目标和生成动力学并不相同。真正好的统一视角应该告诉你“共同核心在哪里”，也应该告诉你“哪些东西绝对不能直接画等号”。

我们最终要回答六个问题

1. 模型认为“数据是怎样产生的”？
2. 训练时网络到底预测什么？
3. Loss 从哪里来？
4. 生成时从什么分布开始？
5. 生成过程是随机的还是确定的？
6. score、noise、velocity 什么时候可以互相转换？

56 · 所有生成模型都在逼近同一个目标：\(p_{data}\)

56.1 我们真正拥有的是什么？

现实中，我们没有真实数据密度：

\[ p_{data}(x) \]

的解析公式。

我们只有一批样本：

\[ x^{(1)},x^{(2)},\ldots,x^{(N)} \sim p_{data} \]

56.2 生成模型希望做到什么？

训练一个模型，使它定义的分布：

\[ p_\theta(x) \]

尽量接近：

\[ p_{data}(x) \]

这样我们就可以从模型中采样：

\[ x\sim p_\theta \]

得到新的、与训练数据分布相似的样本。

56.3 为什么不直接学习一个函数 \(p_\theta(x)\)？

因为真实数据空间通常极高维，并且分布结构非常复杂。直接为任意 x 给出一个规范化概率密度既困难，也很难有效采样。

所以现代生成模型大多会引入“辅助结构”：

VAE

引入潜变量 z，把复杂 x 解释为从简单 z 生成。

Diffusion / Score

引入时间 t 与噪声状态 \(x_t\)，把复杂生成拆成连续或离散的小步骤。

Flow Matching

引入时间 t 与向量场，把简单分布连续运输到数据分布。

56.4 一个最重要的共同图景

容易采样的简单分布 → 学习到的变换 / 动力学 → 复杂数据分布

区别只在于：“中间那座桥”到底怎样定义。

57 · 三层统一框架：分布、学习对象、动力学

57.1 第一层：分布层

问：

起点分布是谁？终点分布是谁？中间是否定义概率路径？

VAE：

\[ z\sim p(z) \] \[ x\sim p_\theta(x|z) \]

Diffusion / Score / Flow：

\[ p_{simple} \longleftrightarrow p_t \longleftrightarrow p_{data} \]

57.2 第二层：学习对象层

问：

神经网络真正被监督去预测哪个数学对象？

可能是：

\[ q_\phi(z|x) \]

可能是：

\[ \epsilon_\theta(x_t,t) \]

可能是：

\[ s_\theta(x_t,t) \approx \nabla_x\log p_t(x) \]

也可能是：

\[ v_\theta(x_t,t) \]

57.3 第三层：动力学 / 采样层

问：

训练结束后，怎样真正产生一个新样本？

可能一次 Decoder 就完成，也可能需要反复应用随机去噪转移，也可能求解 SDE / ODE。

以后读任何新生成模型论文

先不要被模型名字吸引。先问这三层：它定义了什么分布？网络回归什么量？采样动力学是什么？通常很快就能看清它与已有方法的关系。

58 · VAE：把难的观测分布变成“潜变量 + 条件生成”

58.1 VAE 的核心生成故事

\[ z\sim p(z) \] \[ x\sim p_\theta(x|z) \]

因此：

\[ p_\theta(x) = \int p_\theta(x|z)p(z)dz \]

58.2 真正困难的是后验推断

\[ p_\theta(z|x) = \frac{p_\theta(x|z)p(z)} {p_\theta(x)} \]

因为分母边缘似然难算，所以引入：

\[ q_\phi(z|x) \approx p_\theta(z|x) \]

58.3 网络到底在学什么？

Encoder 学：

\[ q_\phi(z|x) \]

Decoder 学：

\[ p_\theta(x|z) \]

58.4 Loss 是什么？

\[ \mathcal L_{ELBO} = \mathbb E_q[ \log p_\theta(x|z) ] - D_{KL}(q_\phi(z|x)\|p(z)) \]

58.5 生成动力学

生成时：

\[ z\sim p(z) \]

然后通常一次 Decoder 前向：

\[ z\to x \]

58.6 VAE 的核心关键词

Latent Variable · Posterior Inference · ELBO · Decoder Likelihood

59 · Diffusion：把一个困难逆映射拆成许多简单去噪步骤

59.1 前向过程

从数据出发逐步加噪：

\[ x_0\sim p_{data} \] \[ x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon \]

最终：

\[ x_T\approx\mathcal N(0,I) \]

59.2 生成模型学习逆过程

\[ p_\theta(x_{t-1}|x_t) \]

经典 DDPM 常让网络预测：

\[ \epsilon_\theta(x_t,t) \]

59.3 Loss

常用简化目标：

\[ \mathbb E [ \| \epsilon - \epsilon_\theta(x_t,t) \|^2 ] \]

59.4 生成动力学

从：

\[ x_T\sim\mathcal N(0,I) \]

开始，反复运行：

\[ x_T\to x_{T-1}\to\cdots\to x_0 \]

59.5 DDPM 的核心关键词

Forward Corruption · Reverse Markov Chain · Denoising · Noise Prediction
DDPM 仍然有变分推断血统

原始 DDPM 的训练可以从变分下界分解得到一系列反向条件分布之间的 KL。它并不是与前面的 ELBO 世界完全断开的另一套数学。DDPM 原始工作也明确讨论了 variational bound 与 denoising score matching 的联系。

60 · Score-based Model：不直接预测密度，而学习“密度往哪里升高”

60.1 Score 定义

\[ s_t(x) = \nabla_x\log p_t(x) \]

它不是概率值本身，而是 log density 在数据空间中的梯度。

60.2 为什么 score 比直接学习密度容易？

直接学习规范化密度往往需要处理配分常数或高维积分；score 对 log density 求导后，任何与 x 无关的规范化常数都会消失。

60.3 Diffusion 为什么自然产生 score？

对高斯扰动：

\[ x_t = \alpha_t x_0 + \sigma_t\epsilon \]

条件 score：

\[ \nabla_{x_t} \log q(x_t|x_0) = - \frac{\epsilon}{\sigma_t} \]

因此知道噪声就等价于知道一个缩放后的 score target。

60.4 连续时间生成

Score-based SDE 框架定义前向随机微分方程：

\[ dx=f(x,t)dt+g(t)dW_t \]

对应的反向时间 SDE 依赖：

\[ \nabla_x\log p_t(x) \]

因此训练好 score 后，可以从噪声通过 reverse SDE 生成数据。

60.5 Probability Flow ODE

同一个 SDE 边缘分布还对应一个确定性 ODE：

\[ \boxed{ \frac{dx}{dt} = f(x,t) - \frac12g(t)^2 s_t(x) } \]

这里时间方向采用前向 SDE 的记号；生成时通常从噪声端反向积分。

60.6 Score 模型的核心关键词

Density Gradient · Denoising Score Matching · Reverse SDE · Probability Flow ODE

61 · Flow Matching：直接学习概率质量如何移动

61.1 选择一条概率路径

\[ p_0=p_{base} \] \[ p_1=p_{data} \]

中间：

\[ p_t,qquad t\in[0,1] \]

61.2 学习速度场

\[ \frac{dx_t}{dt} = v_t(x_t) \]

它必须满足连续性方程：

\[ \partial_t p_t + \nabla\cdot(p_tv_t) = 0 \]

61.3 网络预测什么？

\[ v_\theta(x,t) \]

即速度场。

61.4 CFM 如何提供训练 target？

构造容易计算的条件路径和条件速度：

\[ u_t(x|z) \]

训练：

\[ \mathbb E [ \| v_\theta(x_t,t) - u_t(x_t|z) \|^2 ] \]

61.5 生成

从简单基础分布：

\[ x(0)\sim p_0 \]

解 ODE：

\[ \dot x=v_\theta(x,t) \]

得到：

\[ x(1)\sim p_{data} \]

61.6 Flow Matching 的核心关键词

Probability Path · Vector Field · Conditional Velocity · ODE Transport

62 · 最容易混淆的一页：\(\epsilon\)、\(x_0\)、score、diffusion v、FM velocity

62.1 先固定一个常见连续噪声表示

写成：

\[ x_t = \alpha_t x_0 + \sigma_t\epsilon, \qquad \epsilon\sim\mathcal N(0,I) \]

很多 VP 类型参数化满足：

\[ \alpha_t^2+\sigma_t^2=1 \]

62.2 ε-prediction

网络预测加入的标准高斯噪声：

\[ \hat\epsilon = \epsilon_\theta(x_t,t) \]

62.3 x0-prediction

如果知道噪声，可以解出干净数据估计：

\[ \boxed{ \hat x_0 = \frac{x_t-\sigma_t\hat\epsilon} {\alpha_t} } \]

所以在已知 \(\alpha_t,\sigma_t\) 的情况下，预测 ε 与预测 x0 可以互相转换。

62.4 Score prediction

条件高斯 score：

\[ s = - \frac{\epsilon}{\sigma_t} \]

因此常见噪声参数化下：

\[ \boxed{ \hat s_\theta(x_t,t) = - \frac{ \epsilon_\theta(x_t,t) }{ \sigma_t } } \]

严格说，训练中的条件去噪 target 经过条件期望对应边缘 score；Part VI 已经区分过这两者。

62.5 Diffusion 中的 v-prediction

一些 Diffusion 工作使用：

\[ \boxed{ v = \alpha_t\epsilon - \sigma_t x_0 } \]

若：

\[ \alpha_t^2+\sigma_t^2=1 \]

则由 \(x_t\) 和 v 可以恢复：

\[ \boxed{ x_0 = \alpha_t x_t - \sigma_t v } \] \[ \boxed{ \epsilon = \sigma_t x_t + \alpha_t v } \]

所以 ε-pred、x0-pred、diffusion v-pred 可以看作同一个噪声状态的不同参数化坐标。

62.6 但 diffusion v-prediction 不等于 Flow Matching velocity

这是非常常见的符号陷阱

Diffusion 文献中的 “v-prediction” 通常指 \(v=\alpha\epsilon-\sigma x_0\) 这种网络输出参数化。Flow Matching 中的 velocity \(v_t(x)\) 则是 ODE 中真正满足 \(dx/dt=v_t(x)\) 的时间导数。两者在某些特定参数化/路径下可能建立关系，但定义上绝不是因为都写字母 v 就相同。

62.7 Flow Matching 的线性 velocity

最简单直线路径：

\[ x_t=(1-t)x_0+t x_1 \]

真实条件速度：

\[ \boxed{ \frac{dx_t}{dt} = x_1-x_0 } \]

这才是“trajectory derivative”意义上的 velocity。

63 · 四类训练目标放在同一张桌子上

方法网络学习对象典型目标数学来源
VAE近似后验 + Decoder likelihood最大化 ELBO变分推断 / KL 下界
DDPM噪声、x0 或其他反向参数化常用噪声 MSE变分 bound + 高斯反向 KL 化简
Score\(\nabla_x\log p_t(x)\)Denoising score matchingscore matching / reverse SDE
Flow Matching\(v_t(x)\)velocity regression概率路径 + 连续性方程 / CFM

63.1 为什么后三类 Loss 看起来都像 MSE？

因为它们都把“困难的分布学习问题”转化成了某个局部数学对象的回归：

噪声 target · score target · velocity target → 神经网络监督学习

但“都用 MSE”不意味着学的是同一个对象。

63.2 MSE 只是外壳，target 才决定模型意义

同样：

\[ \|y-f_\theta(x)\|^2 \]

如果 y 是噪声，模型学 denoiser；如果 y 是条件速度，模型学 flow；如果 y 是后验均值，又是另一件事。

64 · 四类采样过程放在同一张桌子上

方法生成起点生成方式典型特点
VAE\(z\sim p(z)\)一次或少量 Decoder 前向采样快；潜变量结构明确
DDPM高斯噪声多步反向随机/离散去噪经典形式步数较多
Score-SDE简单先验数值求解 reverse SDE随机连续动力学
Probability Flow / FM简单先验数值求解 ODE确定性轨迹（给定初值与 solver）

64.1 “确定性 ODE”不代表生成没有随机性

Flow Matching 的 ODE 在给定初始点后是确定的，但初始点本身来自随机分布：

\[ x_0\sim p_{base} \]

因此不同随机初始噪声仍然产生不同样本。

64.2 “随机 SDE”与“确定性 ODE”可以共享边缘分布

Score-based SDE 中，一个 probability flow ODE 可以与对应 SDE 共享相同的时刻边缘分布。

这说明：

同一组概率分布 \(p_t\)，可能由不同的粒子级动力学实现。

“分布怎样随时间变化”与“每个粒子具体怎样走”不是完全相同的问题。

65 · 它们真正的相同点与不同点

65.1 相同点一：都在利用简单分布

标准高斯反复出现，因为它：

• 容易采样；
• 数学性质好；
• 高维情况下仍易操作；
• 可以作为 latent prior 或动态过程的端点。

65.2 相同点二：都把高维分布问题变成局部可训练问题

VAE 把它变成：

\[ q(z|x),\quad p(x|z) \]

Diffusion 把它变成每个噪声时刻的去噪。

Score 把它变成每一点的 log-density gradient。

Flow Matching 把它变成每一点的 velocity。

65.3 相同点三：条件期望悄悄贯穿很多模型

Diffusion 的 denoising target、score matching、CFM 的条件 velocity 回归背后，都存在“平方误差最优解是条件期望”的结构。

这个事实非常值得记住：

\[ \arg\min_f \mathbb E[ \|Y-f(X)\|^2 ] = \mathbb E[Y|X] \]

它解释了为什么我们可以拿一个随机、带条件的 target 训练网络，最后得到一个边缘意义上的确定函数。

65.4 不同点一：VAE 有显式 inference network

VAE 明确学习：

\[ q_\phi(z|x) \]

来解决潜变量后验推断。

标准 Diffusion / Flow Matching 通常没有同样意义上的 Encoder posterior。

65.5 不同点二：Diffusion 的路径通常来自噪声过程

经典 Diffusion 先规定一个数据到噪声的 corruption process。

Flow Matching 可以选择更一般的概率路径，不要求一定来自“逐渐加噪再逆转”的故事。

65.6 不同点三：Score 是密度几何量，Velocity 是运输动力学量

\[ s_t(x)=\nabla_x\log p_t(x) \]

描述密度形状。

\[ v_t(x) \]

描述概率质量运动。

在特定 SDE / probability flow ODE 下：

\[ v_t = f - \frac12g^2s_t \]

才建立明确联系。

65.7 不同点四：路径选择会影响学习与采样难度

即使起点和终点相同，中间走一条弯曲复杂路径还是一条较直接路径，会影响：

• 向量场复杂度；
• ODE solver 需要多少步；
• 数值误差；
• 网络拟合难度。

这正是 Flow Matching 中概率路径与 coupling 设计如此重要的原因。

66 · 从零看一遍完整知识树：你到底一路学了什么？

66.1 数学语言

函数 → 概率 → 条件概率 → 随机变量 → 分布 → 期望 → 方差

66.2 概率模型

高斯 → log → likelihood → maximum likelihood → NLL

66.3 信息与推断

信息量 → 熵 → 交叉熵 → KL → Bayes → posterior → latent variable

66.4 变分推断

难解 posterior → q(z|x) → Jensen → ELBO → amortized inference

66.5 VAE

Gaussian posterior → reparameterization → Decoder likelihood → reconstruction + KL

66.6 Diffusion

Markov noising → Gaussian closed form → reverse process → ε prediction → score

66.7 Flow Matching

ODE → vector field → probability path → continuity equation → conditional velocity regression

66.8 最终统一

复杂数据分布的学习 = 设计一个可训练的中间结构，让简单分布能够到达数据分布

67 · 学完这套主线后，下一步应该学什么？

67.1 如果想继续深入 VAE

可以进入：

• β-VAE 与 disentanglement
• IWAE
• VQ-VAE
• hierarchical VAE
• learned priors / normalizing-flow posterior

67.2 如果想继续深入 Diffusion

建议依次学习：

• DDIM
• continuous-time SDE formulation
• classifier guidance / classifier-free guidance
• x0 / ε / v parameterization
• latent diffusion
• distillation 与 few-step generation

67.3 如果想继续深入 Flow Matching

建议学习：

• Rectified Flow
• OT-CFM
• stochastic interpolants
• Schrödinger Bridge
• consistency / distillation methods
• 不同 ODE solver 与 trajectory straightness

67.4 如果目标是“真正会研究生成模型”

接下来不应该只继续搜集模型名，而要补三块数学：

线性代数

矩阵、特征值、Jacobian、协方差、低维子空间。

多元微积分

梯度、Jacobian、divergence、change of variables。

随机过程

Brownian motion、SDE、Fokker–Planck、Itô calculus。

学完这些后，再看现代生成模型论文时，大量公式会从“符号墙”变成可追踪的动力学和概率论。

Part VIII · 最终总结

一句话描述 VAE

用变分后验解决潜变量模型的难解推断，并通过 ELBO 联合学习 Encoder 与 Decoder。

一句话描述 Diffusion

人为把数据逐渐变成简单噪声，再学习一个反向过程逐步恢复数据。

一句话描述 Score-based Model

学习每个噪声时刻的 log-density gradient，用它构造反向随机或确定性生成动力学。

一句话描述 Flow Matching

选择一条连接简单分布与数据分布的概率路径，直接回归推动这条路径的速度场。

如果你现在重新回到最初的 VAE 公式

你已经不仅能解释它，还能把它放进更大的生成模型坐标系里：VAE 解决 latent posterior；Diffusion 把复杂生成拆成噪声时间路径；Score 描述密度几何；Flow Matching 描述概率运输动力学。它们不是孤立的四套知识，而是几种不同的“把简单随机性塑造成复杂数据”的数学方案。
