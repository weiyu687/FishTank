1. 什么是 Agent？与普通聊天、工作流有什么区别？

Agent 根据目标、观测和状态选择下一步动作，在工具反馈后继续决策。普通聊天主要输出文本；固定工作流的执行顺序由程序预先约束；Agent 将部分运行时决策交给模型。现实系统常采用混合方案：固定流程管边界，模型处理开放问题。

追问：何时不用 Agent？字段抽取、固定规则审批和可枚举业务流程，优先结构化输出或确定性代码。引入 Agent 应证明动态决策带来的收益超过延迟、成本与失控风险。

2. Tool calling 的完整过程是什么？

应用把工具描述和参数 schema 提供给模型；模型返回工具名称与参数；运行时校验、鉴权、执行；将结果关联到调用 ID；模型继续生成回答或下一次调用。模型生成调用请求，不是模型本身直接访问数据库。

追问：JSON 合法就安全吗？不是。schema 只能限制形式，还需校验资源归属、数值范围、业务状态、并发版本和调用者权限。

3. 工具为什么会选错？

常见原因是名称含糊、多个工具职责重叠、描述缺乏触发条件、参数语义不清、工具数量过多或上下文缺失。先分析误选矩阵，再调整描述、合并重复工具或按任务动态筛选。

不要只增加提示词长度。使用“正确工具选择率”和“端到端任务成功率”共同评估，工具选对但参数错仍然失败。

4. ReAct、规划执行和反思有什么区别？

ReAct 式循环交替决策、行动与观察；规划执行先形成任务分解，再逐项实施并修订；反思增加结果检查或修改环节。它们是控制策略，不是可靠性的保证。

规划适合长任务，但计划可能过早锁死错误假设；逐步决策灵活，但可能反复探索；反思增加成本，也可能把正确答案改错。必须有外部验收信号，如测试、引用或业务状态。

5. Agent 如何知道任务完成？

把完成条件表达成可检查结果：文件生成且校验通过、订单状态确认、答案的关键结论有证据。模型说“完成”只是候选信号。设置最大步数、预算、重复调用检测和人工接管作为额外终止条件。

追问：达到步数上限是不是失败？通常属于未完成，应返回已完成项、失败原因和可恢复状态，不能包装成成功。

6. LangChain、LangGraph、Deep Agents 怎么选？

LangChain 提供模型工具抽象与 Agent 构建；LangGraph 提供状态、图执行和持久化控制；Deep Agents 组合文件、子任务和记忆等工作环境。选型看任务需要的可控程度与内置能力，不以框架层数判断项目水平。官方栈说明

项目回答应说明实际用了哪些组件：状态保存在哪里、哪些边是确定性的、哪些选择由模型做、异常在哪里恢复。

7. State、context、store 分别放什么？

State 存当前执行可更新的数据；运行时 context 提供用户身份、配置或服务依赖；store 放跨执行共享的信息。不要把用户可以修改的消息当作可信身份，不要把所有历史全文塞入每轮 state 后直接发给模型。

多个节点同时写同一状态时，需要定义合并规则。列表追加可能产生重复，计数累加可能因重试而重复计算，规则必须匹配业务语义。

8. 多 Agent 一定比单 Agent 好吗？

不一定。收益来自任务可分解、上下文隔离、专业工具限制与并行；代价是通信、重复工作、冲突和额外模型调用。先建立单 Agent 基线，再比较质量与成本。

面试中应回答如何分工、如何传递证据、谁负责最终验收、并发是否真的缩短关键路径。几个角色互相聊天不是工程收益的证明。

9. MCP 是什么，和 function calling 什么关系？

MCP 定义宿主、客户端和服务端之间连接外部能力的协议；function calling 是模型表达工具调用意图的接口形式。MCP Server 的能力经过客户端接入后，仍需要应用决定哪些工具展示给模型以及如何授权。MCP 架构

接入 MCP 不意味着服务可信，也不自动解决租户隔离、凭证最小化和结果注入。工具描述、输出和服务器升级都需要治理。

10. Skill、Prompt、Tool、Memory 怎么区分？

Prompt 约束当前行为，Tool 执行动作，Skill 封装可复用流程与资料，Memory 保存跨交互有价值的信息。同一份 Markdown 可以承担不同角色，关键是加载时机、作用范围和更新权限。

举例：退款 policy 是知识；退款审核步骤是 Skill；query_order 是 Tool；用户偏好的语言是 Memory。把政策写进个人可编辑记忆会混淆权限。

11. 结构化输出为什么仍然会失败？

schema 合法不等于事实正确。模型可能填入错误编号、编造来源、输出语义矛盾值。需要字段级校验、跨字段约束、必要的外部查询和有限次数修复。

对未找到的事实设计 null、unknown 或明确错误类型，而不是强迫模型为每个字段填一个看似合理的值。

12. 温度设为零是否可复现？

只能降低部分采样随机性，不保证全链路完全确定。模型服务版本、并行执行、检索排序、时间相关工具和后端计算都可能变化。记录模型与应用版本、工具输入输出、知识索引版本及运行配置，才能定位差异。
