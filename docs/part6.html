PART VI · DIFFUSION MODELS

Diffusion：把“生成一个复杂样本”拆成很多个简单的小步骤

VAE 的思路是：从一个简单潜变量 z 出发，通过 Decoder 一次性生成复杂数据 x。Diffusion 换了一个视角：先定义一个可控的“破坏过程”，逐步把真实数据变成噪声；再学习这个过程的逆过程，让噪声一步步回到数据。

这一 Part 的目标

从概率链本身推到经典 DDPM 的训练目标，而不是从“网络预测噪声”倒背公式。你会看到 \(\beta_t\)、\(\alpha_t\)、\(\bar\alpha_t\)、\(\epsilon\)-prediction 为什么出现，以及 score \(\nabla_x\log p_t(x)\) 与噪声预测之间的联系。

为什么 Diffusion 接在 VAE 后面很自然？

前五个 Part 已经给出了几乎全部需要的数学工具：

高斯分布 → 条件概率 → KL → ELBO → 变分推断 → 神经网络参数化概率分布

Diffusion 仍然大量使用高斯、条件分布、KL 和 ELBO。不同的是，它不只引入一个潜变量 z，而是引入一整条逐渐变噪的随机变量链：

\[ x_0,x_1,x_2,\ldots,x_T \]

其中 \(x_0\) 是真实数据，\(x_T\) 最终接近标准高斯噪声。

33 · 为什么“逐步加噪”反而有助于生成？

33.1 直接生成为什么难？

真实图像分布非常复杂：高维、强相关、多峰。若要求一个模型直接把简单噪声映射成高质量图像，它必须一次性完成非常复杂的分布变换。

33.2 把大问题拆成很多小问题

Diffusion 的核心直觉是：

复杂的大变化 → 拆成很多个局部、微小、容易近似的变化

前向过程每一步只加入一点高斯噪声，所以每一步的条件分布非常简单；如果噪声加得足够多，最终复杂数据分布会逐渐被“抹平”，趋近简单高斯。

33.3 训练时为什么要先学“破坏”？

前向加噪过程不是需要学习的，它由我们人为规定。这样我们能随时制造：

\[ (x_0,x_t) \]

训练对，其中 \(x_0\) 是干净数据，\(x_t\) 是某个噪声等级下的版本。

模型真正学习的是逆方向：

略带噪声的 \(x_t\) → 更干净的 \(x_{t-1}\)

33.4 为什么不用一步直接从 \(x_T\) 回到 \(x_0\)？

因为从几乎纯噪声直接恢复完整图像仍然是一个极难的多模态问题。将它拆成很多小逆步骤后，每一步只需要估计“当前位置应该往数据分布方向移动一点点”。

34 · 马尔可夫链：每一步只依赖上一步

34.1 什么是马尔可夫性质？

对随机变量序列：

\[ x_0,x_1,\ldots,x_T \]

若满足：

\[ q(x_t|x_{t-1},x_{t-2},\ldots,x_0) = q(x_t|x_{t-1}) \]

就说它具有一阶马尔可夫性质。

直觉上：知道当前状态 \(x_{t-1}\) 后，更早的历史不会额外影响下一步 \(x_t\)。

34.2 整条前向链的联合分布

利用概率乘法法则：

\[ q(x_{1:T}|x_0) = \prod_{t=1}^{T} q(x_t|x_{t-1}) \]

这里 \(x_{1:T}\) 是简写，表示 \(x_1,\ldots,x_T\)。

34.3 为什么使用 q 而不是 p？

经典 DDPM 记号中，前向扩散过程通常记为 q，因为它是我们人为规定、无需学习的“已知过程”；反向生成模型记为 \(p_\theta\)，因为它需要神经网络学习。

字母只是约定

这和 VAE 中 q 表示近似后验的传统有关，但不要把“q 永远等于 Encoder”当成规则。看公式时要看它的定义。

35 · 前向扩散：每一步到底怎样加噪？

35.1 定义一步前向过程

DDPM 规定：

\[ q(x_t|x_{t-1}) = \mathcal N \left( x_t; \sqrt{1-\beta_t}\,x_{t-1}, \beta_t I \right) \]

其中：

\[ 0<\beta_t<1 \]

\(\beta_t\) 控制第 t 步加入多少噪声。

35.2 把高斯采样写成重参数化形式

根据 Part II 与 VAE 已经使用过的高斯变换：

\[ x_t = \sqrt{1-\beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\epsilon_t \]

其中：

\[ \epsilon_t\sim\mathcal N(0,I) \]

35.3 为什么还要乘 \(\sqrt{1-\beta_t}\)？

如果只写：

\[ x_t=x_{t-1}+\sqrt{\beta_t}\epsilon_t \]

信号方差会不断膨胀。乘上 \(\sqrt{1-\beta_t}\) 相当于在加入新噪声的同时略微缩小旧信号，使总体尺度保持受控。

35.4 引入 \(\alpha_t\)

为了简化公式，定义：

\[ \alpha_t=1-\beta_t \]

于是：

\[ q(x_t|x_{t-1}) = \mathcal N \left( \sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)I \right) \]

采样式变成：

\[ x_t = \sqrt{\alpha_t}x_{t-1} + \sqrt{1-\alpha_t}\epsilon_t \]

35.5 噪声日程 noise schedule

一整组：

\[ \beta_1,\beta_2,\ldots,\beta_T \]

称为噪声日程。早期 DDPM 常采用较小、逐步变化的 \(\beta_t\)。具体 schedule 是工程设计问题；数学上只需要知道它决定每一步保留多少旧信号、加入多少新噪声。

36 · 最关键的闭式：如何一步得到任意 \(x_t\)？

36.1 为什么需要闭式？

如果训练时为了得到 \(x_t\)，必须真的从 \(x_0\) 连续模拟 t 次加噪，那么训练会很低效。

幸运的是，高斯线性变换可以合并，我们可以直接从 \(x_0\) 一步采样任意 \(x_t\)。

36.2 先展开两步

第一步：

\[ x_1 = \sqrt{\alpha_1}x_0 + \sqrt{1-\alpha_1}\epsilon_1 \]

第二步：

\[ x_2 = \sqrt{\alpha_2}x_1 + \sqrt{1-\alpha_2}\epsilon_2 \]

代入 \(x_1\)：

\[ x_2 = \sqrt{\alpha_2\alpha_1}x_0 + \sqrt{\alpha_2(1-\alpha_1)}\epsilon_1 + \sqrt{1-\alpha_2}\epsilon_2 \]

36.3 两个独立高斯噪声的线性组合仍是高斯

若 \(\epsilon_1,\epsilon_2\sim\mathcal N(0,I)\) 且独立，则：

\[ a\epsilon_1+b\epsilon_2 \sim \mathcal N(0,(a^2+b^2)I) \]

上式噪声部分的总方差为：

\[ \alpha_2(1-\alpha_1)+(1-\alpha_2) \]

展开：

\[ \alpha_2-\alpha_1\alpha_2+1-\alpha_2 = 1-\alpha_1\alpha_2 \]

因此可以重新写成一个标准高斯噪声 \(\epsilon\)：

\[ x_2 = \sqrt{\alpha_1\alpha_2}x_0 + \sqrt{1-\alpha_1\alpha_2}\epsilon \]

36.4 定义累计乘积 \(\bar\alpha_t\)

\[ \bar\alpha_t = \prod_{s=1}^{t}\alpha_s \]

递推下去得到：

\[ \boxed{ q(x_t|x_0) = \mathcal N \left( \sqrt{\bar\alpha_t}x_0, (1-\bar\alpha_t)I \right) } \]

对应采样式：

\[ \boxed{ x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon, \qquad \epsilon\sim\mathcal N(0,I) } \]

36.5 这条公式为什么如此重要？

训练时我们可以：

随机抽一个真实 \(x_0\) → 随机抽一个时间 t → 随机抽 \(\epsilon\) → 直接构造 \(x_t\)

不需要执行前面 t−1 步。

36.6 当 t 很大时发生什么？

若噪声日程让：

\[ \bar\alpha_T\approx0 \]

那么：

\[ x_T \approx \epsilon \sim\mathcal N(0,I) \]

也就是说，复杂数据最终被推向一个简单、已知、容易采样的高斯分布。

37 · 反向过程：生成模型真正要学什么？

37.1 生成从哪里开始？

既然前向过程末尾：

\[ x_T\approx\mathcal N(0,I) \]

那么生成时可以从：

\[ x_T\sim\mathcal N(0,I) \]

开始。

37.2 理想的反向链

我们希望一步步：

\[ x_T\to x_{T-1}\to\cdots\to x_0 \]

所以需要每一步反向条件分布：

\[ p_\theta(x_{t-1}|x_t) \]

整个反向生成模型写成：

\[ p_\theta(x_{0:T}) = p(x_T) \prod_{t=1}^{T} p_\theta(x_{t-1}|x_t) \]

37.3 为什么反向条件也常设为高斯？

当每一步 \(\beta_t\) 很小时，前向过程只做一个很小的高斯扰动。对这样的局部变化，真实逆条件可以很好地用高斯近似。

因此经典 DDPM 参数化：

\[ p_\theta(x_{t-1}|x_t) = \mathcal N \left( x_{t-1}; \mu_\theta(x_t,t), \Sigma_\theta(x_t,t) \right) \]

神经网络输入不仅包括 \(x_t\)，还必须知道当前时间 t，因为不同噪声等级需要不同的去噪行为。

37.4 为什么不能直接写真实 \(q(x_{t-1}|x_t)\)？

因为：

\[ q(x_{t-1}|x_t) \]

要对未知的真实数据分布进行边缘化。它不是我们仅靠前向高斯定义就能直接获得的简单分布。

但如果训练时知道原始干净样本 \(x_0\)，情况会变得更简单。

38 · 真实反向后验 \(q(x_{t-1}|x_t,x_0)\)

38.1 为什么多给一个 \(x_0\) 后就好算？

训练期间，我们既知道干净数据 \(x_0\)，也能制造 \(x_t\)。于是可以考虑：

\[ q(x_{t-1}|x_t,x_0) \]

根据贝叶斯关系：

\[ q(x_{t-1}|x_t,x_0) \propto q(x_t|x_{t-1}) q(x_{t-1}|x_0) \]

右边两项都是高斯，因此乘积仍然是高斯。

38.2 结果

经过高斯配方（complete the square）可得到：

\[ q(x_{t-1}|x_t,x_0) = \mathcal N ( x_{t-1}; \tilde\mu_t(x_t,x_0), \tilde\beta_t I ) \]

其中：

\[ \tilde\beta_t = \frac{1-\bar\alpha_{t-1}} {1-\bar\alpha_t} \beta_t \]

均值为：

\[ \tilde\mu_t = \frac{ \sqrt{\bar\alpha_{t-1}}\beta_t }{ 1-\bar\alpha_t }x_0 + \frac{ \sqrt{\alpha_t}(1-\bar\alpha_{t-1}) }{ 1-\bar\alpha_t }x_t \]

38.3 这里为什么不把“高斯配方”完全展开？

它需要把两个多维高斯指数项相加，再对 \(x_{t-1}\) 完成平方。这个代数过程较长，但没有引入新的概率思想。

对理解 DDPM 主线，关键是知道：

前向一步是高斯 + 从 \(x_0\) 到 \(x_{t-1}\) 也是高斯 → 条件后验仍能得到解析高斯

如果后续需要，我们可以单独增加“附录：\(q(x_{t-1}|x_t,x_0)\) 完整配平方推导”。

38.4 把 \(x_0\) 改写成噪声 \(\epsilon\)

第 36 节已经有：

\[ x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon \]

解出 \(x_0\)：

\[ x_0 = \frac{ x_t-\sqrt{1-\bar\alpha_t}\epsilon }{ \sqrt{\bar\alpha_t} } \]

代入 \(\tilde\mu_t\) 后可以整理为：

\[ \boxed{ \tilde\mu_t = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t} {\sqrt{1-\bar\alpha_t}} \epsilon \right) } \]

38.5 一个非常关键的转折

如果我们知道加到 \(x_0\) 上的噪声 \(\epsilon\)，就能算出正确反向高斯均值。

于是“学习反向均值”可以改写成：

给定 \(x_t,t\)，让神经网络预测当初加入的噪声 \(\epsilon\)

39 · 从变分下界到噪声预测 Loss

39.1 Diffusion 也可以从最大似然出发

目标仍然是让真实数据 \(x_0\) 在模型下概率高：

\[ \log p_\theta(x_0) \]

像 VAE 一样，直接计算涉及一整条隐藏变量链：

\[ x_1,\ldots,x_T \]

因此可以使用变分下界。

39.2 前向链 q 扮演变分分布

定义：

\[ q(x_{1:T}|x_0) = \prod_{t=1}^{T}q(x_t|x_{t-1}) \]

可以对 \(\log p_\theta(x_0)\) 构造 ELBO。经过分解后，目标包含一系列 KL：

\[ D_{KL} \left( q(x_{t-1}|x_t,x_0) \| p_\theta(x_{t-1}|x_t) \right) \]

也就是说：让学习到的反向一步，逼近真实的“带 \(x_0\) 条件”的反向后验。

39.3 两个高斯之间的 KL

如果两者方差固定或按特定方式设定，那么 KL 中与神经网络有关的主要部分会变成均值之间的平方误差：

\[ \|\tilde\mu_t-\mu_\theta(x_t,t)\|^2 \]

而上一节已经知道，\(\tilde\mu_t\) 可以完全用 \(x_t\) 和真实噪声 \(\epsilon\) 表达。

39.4 参数化网络预测噪声

定义网络：

\[ \epsilon_\theta(x_t,t) \]

并把反向均值参数化为：

\[ \mu_\theta(x_t,t) = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t} {\sqrt{1-\bar\alpha_t}} \epsilon_\theta(x_t,t) \right) \]

于是均值误差最终等价于一个带时间权重的噪声预测误差。

39.5 经典简化目标

DDPM 实践中常使用简化后的：

\[ \boxed{ \mathcal L_{simple} = \mathbb E_{ x_0,t,\epsilon } \left[ \| \epsilon - \epsilon_\theta(x_t,t) \|^2 \right] } \]

其中：

\[ x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon \]

训练步骤因此非常简洁：

取真实 \(x_0\) → 随机 t → 随机噪声 \(\epsilon\) → 构造 \(x_t\) → 网络预测 \(\epsilon\) → MSE

39.6 为什么最终又变成 MSE？

这里的 MSE 和 VAE 图像重建 MSE 来源不同。

VAE 常见 MSE

来自对 \(p_\theta(x|z)\) 采用固定方差高斯观测模型。

DDPM 噪声 MSE

来自反向高斯 KL 在特定参数化下对均值误差的化简。

共同点

两者最终都可追溯到高斯负对数概率中的平方项。

39.7 “simple loss” 与完整 ELBO 完全相同吗？

不是严格逐项相同。原始 DDPM 的变分目标带有依赖 t 的权重和边界项；常用 \(\mathcal L_{simple}\) 去掉了一些权重，作为效果更好的简化训练目标。

不要把“DDPM Loss 就是 MSE”理解成理论起点

正确逻辑是：最大似然/ELBO → 每步高斯 KL → 均值参数化 → 噪声预测 → 简化 MSE。

40 · Score：为什么“预测噪声”也可以看成“学习概率密度的方向”？

40.1 先补一个必要工具：梯度

一维函数 \(f(x)\) 的导数告诉我们函数沿 x 方向如何变化。

多维输入：

\[ x=(x_1,\ldots,x_d) \]

对每个维度分别求偏导并排成向量：

\[ \nabla_x f(x) = \left( \frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_d} \right) \]

它叫梯度。

梯度指向函数增长最快的局部方向。

40.2 什么是 score？

对概率密度 \(p(x)\)，score 定义为：

\[ \boxed{ s(x) = \nabla_x\log p(x) } \]

注意这里是对数据 x 求梯度，不是对神经网络参数 \(\theta\) 求梯度。

40.3 高斯的 score 是什么？

一维标准高斯：

\[ p(x) \propto \exp(-x^2/2) \]

所以：

\[ \log p(x) = C-\frac{x^2}{2} \]

对 x 求导：

\[ \frac{d}{dx}\log p(x) = -x \]

因此 score 会把远离 0 的点指回高密度中心。

40.4 条件高斯 \(q(x_t|x_0)\) 的 score

我们知道：

\[ q(x_t|x_0) = \mathcal N ( \sqrt{\bar\alpha_t}x_0, (1-\bar\alpha_t)I ) \]

高斯 log density 对 \(x_t\) 的梯度为：

\[ \nabla_{x_t} \log q(x_t|x_0) = - \frac{ x_t-\sqrt{\bar\alpha_t}x_0 }{ 1-\bar\alpha_t } \]

而：

\[ x_t-\sqrt{\bar\alpha_t}x_0 = \sqrt{1-\bar\alpha_t}\epsilon \]

所以：

\[ \boxed{ \nabla_{x_t} \log q(x_t|x_0) = - \frac{\epsilon} {\sqrt{1-\bar\alpha_t}} } \]

40.5 这说明预测噪声和预测 score 只差一个已知缩放

如果网络能预测：

\[ \epsilon_\theta(x_t,t) \]

那么就可以得到一个对应的 score 估计：

\[ s_\theta(x_t,t) \approx - \frac{ \epsilon_\theta(x_t,t) }{ \sqrt{1-\bar\alpha_t} } \]

因此经典 DDPM 的噪声预测，与 score-based generative modeling 在数学上有非常紧密的联系。

40.6 条件 score 与边缘 score 要区分

上面直接推导的是：

\[ \nabla_{x_t}\log q(x_t|x_0) \]

而生成时真正需要理解的是噪声时刻的边缘分布：

\[ q_t(x_t) = \int q(x_t|x_0)p_{data}(x_0)dx_0 \]

的 score：

\[ \nabla_{x_t}\log q_t(x_t) \]

通过 denoising score matching，可以证明用带噪样本训练条件 score 的回归目标，会得到边缘 score 的正确最优解。这个证明涉及条件期望，我们把它留在后续“Score/Diffusion 附录”，避免在主线中突然展开另一条较长推导。

41 · 采样：模型如何真的从噪声生成图像？

41.1 第一步：采纯噪声

\[ x_T\sim\mathcal N(0,I) \]

41.2 从 T 走到 1

每个时间步，网络先预测：

\[ \epsilon_\theta(x_t,t) \]

再得到反向均值：

\[ \mu_\theta(x_t,t) = \frac1{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t} {\sqrt{1-\bar\alpha_t}} \epsilon_\theta(x_t,t) \right) \]

然后按反向高斯采样：

\[ x_{t-1} = \mu_\theta(x_t,t) + \sigma_t z \]

其中：

\[ z\sim\mathcal N(0,I) \]

在最后一步通常不再额外加入噪声。

41.3 为什么生成很慢？

经典 DDPM 需要很多次串行网络调用：

x_T → 网络 → x_{T-1} → 网络 → … → 网络 → x_0

这也是后来 DDIM、更少步采样、蒸馏、ODE 视角以及 Flow Matching 等方向的重要动机之一。

41.4 网络通常是什么结构？

图像 Diffusion 经典实现常使用 U-Net 类结构，并把时间 t 编码成 time embedding 输入网络。

但“U-Net”不是 Diffusion 的数学定义。理论核心是：

学习随噪声时间变化的反向去噪/score 场

具体神经网络结构可以变化。

42 · Diffusion 的局限，以及为什么会走向 Flow Matching

42.1 优势：训练目标稳定

随机选 t、加已知高斯噪声、预测噪声，形成了非常直接的监督信号。训练通常比对抗生成更稳定。

42.2 代价：采样需要很多步

经典 Diffusion 的生成是一个多步反向随机过程。每一步都需要模型推理，速度是明显成本。

42.3 离散时间只是唯一选择吗？

不是。把时间步越来越细，可以走向连续时间极限。

前向加噪可以写成随机微分方程（SDE），反向生成也可以写成 reverse-time SDE；还存在一个与之共享边缘分布的 probability flow ODE。

这些连续时间观点会逐渐把问题从：

“每一步应该去掉多少噪声？”

改写成：

“在时间 t、位置 x，样本应该沿哪个速度方向移动？”

42.4 这正是 Flow Matching 的语言

Flow Matching 不一定先定义一个随机加噪再反演，而是直接学习一个时间相关向量场：

\[ \frac{dx_t}{dt}=v_t(x_t) \]

使简单基础分布通过连续流被运输到数据分布。

但要真正理解这条式子，还需要补齐：

导数 → 常微分方程 ODE → 向量场 → 概率路径 → 连续性方程

这就是 Part VII。

Part VI · Diffusion 知识闭环

1. 前向一步

\[ q(x_t|x_{t-1}) = \mathcal N ( \sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)I ) \]

2. 任意时刻闭式

\[ \boxed{ x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon } \]

3. 末端接近简单高斯

\[ x_T\approx\mathcal N(0,I) \]

4. 反向模型

\[ p_\theta(x_{t-1}|x_t) = \mathcal N ( \mu_\theta(x_t,t), \Sigma_t ) \]

5. 真实训练后验可解析

\[ q(x_{t-1}|x_t,x_0) = \mathcal N ( \tilde\mu_t, \tilde\beta_tI ) \]

6. 用噪声参数化均值

\[ \mu_\theta(x_t,t) = \frac1{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t} {\sqrt{1-\bar\alpha_t}} \epsilon_\theta(x_t,t) \right) \]

7. 常用简化训练目标

\[ \boxed{ \mathcal L_{simple} = \mathbb E [ \|\epsilon-\epsilon_\theta(x_t,t)\|^2 ] } \]

8. 噪声预测与 score

\[ \boxed{ s_\theta(x_t,t) \approx - \frac{ \epsilon_\theta(x_t,t) }{ \sqrt{1-\bar\alpha_t} } } \]
现在 Diffusion 的核心符号也都有来源了

\(\beta_t\) 是一步噪声量；\(\alpha_t=1-\beta_t\) 是一步信号保留率；\(\bar\alpha_t\) 是累计信号保留率；\(\epsilon\) 来自高斯闭式采样；噪声 MSE 来自反向高斯 KL 的化简；score 是 log density 对数据的梯度。
